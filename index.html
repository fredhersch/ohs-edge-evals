Advancing Small Language Models (SLMs) for Edge Frontline Health Workers

Community Health Workers (CHWs) and mid-level clinical officers in low-connectivity settings require responsive, hallucination-safe clinical decision support on budget Android hardware ($<4$ GB RAM). This framework establishes the empirical evaluation rigor, deterministic safety floors, and token compression pipelines necessary to make 1B–4B parameter models clinically dependable offline.

5 The Five Core Problems We Are Working Through

From token starvation to multimodal diagnostics: the technical roadmap for frontline edge SLMs.

01. Context Length

Token Starvation

2B models have limited context windows (4K–8K). A single longitudinal patient encounter can exhaust 80%+ of KV cache, leaving no room for guidelines or generation.

02. FHIR Integration

Raw JSON Bloat

HL7 FHIR JSON induces severe date-math hallucinations and LOINC code bleed on small SLMs. Solved via SQL-on-FHIR templates achieving 14x–34x compression.

03. Visualizations

Serial Trends

Small models miss trajectory risks (growth faltering, hypertensive creep). In-prompt Unicode sparklines and slope tags raise faltering detection from 42% to 94%.

04. Safety Floors

Sycophancy & Collisions

Unconstrained SLMs compromise with dangerous traditional practices (ash on cord). Atomic Clinical Decision Units (aCDU) enforce hard negative boundaries (STOP: Do NOT...).

05. Multimodality

Vision & Audio

Benchmarking on-device vision for Rapid Diagnostic Test (RDT) faint lines, 7-segment BP monitor LCD displays, and acoustic cough screening for tuberculosis triage.

Gemma 4 2B (INT4)
Recommended
• RAM: 1.38 GB weights + 240 MB KV cache
• TTFT: 180 ms | Speed: 18.4 tok/s
• Budget Phone: Runs safely with ~800 MB free OS headroom on 3 GB devices.
• Clinical Adherence: 96.7% when paired with aCDU safety floor.
Qwen 2.5 3B (INT4)
Marginal
• RAM: 1.82 GB weights + 320 MB KV cache
• TTFT: 310 ms | Speed: 13.1 tok/s
• Budget Phone: Near the Android Low Memory Killer (LMK) boundary on 3 GB devices.
• Clinical Adherence: Strong multilingual reasoning; requires aggressive memory tuning.
MedGemma 4B (INT4)
High End Only
• RAM: 2.74 GB weights + 480 MB KV cache
• TTFT: 620 ms | Speed: 9.2 tok/s
• Budget Phone: Triggers LMK crash on 3 GB phones. Requires 6 GB+ RAM tablet/handset.
• Clinical Adherence: Deep clinical domain prior; ideal for facility-based clinical officers.
