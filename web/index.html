Qualitative Failure Analysis: The Three Pathologies

Pathology 1

LOINC Numeric Code Bleed (Original Standard Tokempic)

Standard SQL-on-FHIR templates often output nested observation component codes verbatim into Markdown table columns. In Case 1 (Fatima Bello), systolic (8480-6) and diastolic (8462-4) codes were juxtaposed with measurements.

× Original Tokempic Model Output
"Blood pressure was previously 126/8480-6 and 8462-4: 82. Current reading is elevated at 148/96."

2B model confuses LOINC code strings with systolic blood pressure readings.

✓ Optimized Tokempic Fix
"Blood pressure was 126/82 mmHg (normal) and jumped to 148/96 mmHg (high)."

Pre-concatenation in SQL-on-FHIR views (vitals.json) eliminates technical code tokens entirely.

Pathology 2

Critical Care Blindspot via Resource Omission (Original Standard Tokempic)

Standard FHIR summarizers focus on traditional encounters, conditions, and vitals—completely omitting FHIR Task resources (CHW referral tracking) and bedside point-of-care observations (urinalysis dipsticks).

• Fatima Bello (Case 1): Overdue emergency hospital referral for pre-eclampsia workup was completely invisible to Original Tokempic (0% capture rate).
• Mercy Ofori (Case 4): 3+ glucosuria dipstick reading was omitted because non-vital observation resources were not included.
• Optimized Fix: Dedicated tasks.json and observations.json SQL-on-FHIR views guarantee 100% visibility of active CHW workflows.
Pathology 3

Date-Math Arithmetic Breakdown (Raw FHIR JSON)

Quantized 2B models lack internal arithmetic circuitry to reliably calculate age in months from an ISO string (birthDate: "2025-06-10") relative to the visit timestamp (2026-10-18).

Kofi Mensah (16m Infant) → Raw FHIR Hallucination
"Kofi Mensah is a 25-year-old male from Danfa Village, Ghana. He was born on June 10, 2025."

Model latched onto the year digits '25' and declared the 16m infant an adult.

Zainab Umaru (4y Child) → Raw FHIR Hallucination
"Zainab Umaru is a 21-year-old female from Sabon Gari, Nigeria."

Model confused birth year 2022 with age 21, misclassifying severe pediatric pneumonia.

Architectural Implications for OHS Edge on Mobile Devices

1. Context Window Preservation for Mini-RAG

On budget Android devices, edge runtimes (LiteRT / MediaPipe) typically allocate a 2,048 or 4,096 token context window to constrain RAM consumption to under 1.5–2.0 GB. Raw FHIR consumes ~1,000 to 3,500 tokens just for the patient record, leaving almost zero room for retrieved MOH/WHO clinical guidelines. Optimized Tokempic consumes ~330 tokens, leaving ~3,700 tokens free for guideline chunks, counseling talking points, and CHW prompt instructions.

2. Battery Life and Prompt Prefill Latency

On ARM mobile chipsets without large Neural Processing Units (NPUs), prompt prefill latency scales linearly with input token count. Reducing input tokens by 3.1x to 6x directly reduces prefill compute time and battery drain, enabling consistent sub-2-second response times on low-cost devices.

6

Actionable Engineering & Clinical Recommendations

1. Mandate SQL-on-FHIR Pre-Filtering

Never expose raw FHIR JSON bundles directly to edge SLMs. All LLM inputs must pass through deterministic Tokempic views.

2. Pre-Compute Relative Age Units

Views should always emit explicit age strings (16m, 4y, 28y) alongside ISO birthdates to prevent date arithmetic hallucinations.

3. Deploy Dedicated tasks.json and observations.json Views

Always include CHW referral tasks and POC bedside dipsticks in the SQL-on-FHIR schema to avoid clinical blindspots.

4. Strip Technical Numeric Codes at View Layer

Strip raw LOINC and SNOMED numeric code strings in chw-views/, retaining only clean human-readable displays to eliminate numeric token confusion.
